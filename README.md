# Jokewala

Jokewala is a curated repository and application ecosystem for authentic Hindi and Hinglish humor.

## Dataset Location
The complete, categorized dataset is located in [`hinglish-jokes-dataset/`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/):

- [`README.md`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/README.md) - Complete documentation, taxonomy, schema, and methodology.
- [`categories.json`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/categories.json) - 45 categorized taxonomy entries with metadata and counts.
- [`jokes-master.json`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/jokes-master.json) - Master dataset with research attribution, URLs, and safety flags.
- [`exports/`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/exports/) - Production-ready lightweight exports (`all-jokes.json`, `clean-jokes.json`, `jokes.csv`, `categories.json`).
- [`sources/`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/sources/) - Source registry ([`sources.csv`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/sources/sources.csv)) and summary analysis ([`source-summary.md`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/sources/source-summary.md)).
- [`reports/`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/reports/) - Live statistical audit ([`dataset-report.md`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/reports/dataset-report.md)).
- [`research-log/`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/research-log/) - Research checklist and progress ledger ([`progress.md`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/research-log/progress.md)).
- [`01-one-liners/`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/01-one-liners/) to [`45-other/`](file:///d:/my-apps/Jokewala/hinglish-jokes-dataset/45-other/) - Category folders containing human-readable markdown files.
